# Contributor License Agreement

This is a lightweight CLA for contributions to this repository. It exists so
the maintainer can keep offering the official builds (Chrome Web Store,
Mozilla Add-ons, any future store) without those builds themselves being
bound by AGPL-3.0's network-use clause, and so the project can later relicense
or dual-license the codebase if that is ever needed — without having to track
down every past contributor for permission.

By opening a pull request against this repository, you agree to the
following, for the contribution you are submitting:

1. **You own it, or you have the right to submit it.** The contribution is
   your own original work, or you otherwise have the right to submit it under
   these terms (for example, your employer has given you permission).
2. **You grant the maintainer a license to use it however they choose,** in
   addition to the AGPL-3.0 terms the repository is already published under.
   This includes using your contribution in the official closed-source
   builds, other licenses, or any future relicensing of the project, without
   owing you anything beyond what AGPL-3.0 itself requires.
3. **You keep your own rights.** This agreement does not take anything away
   from you — you still own your contribution and may reuse it elsewhere.
4. **No warranty.** Your contribution is provided "as is", same as the rest
   of the project.

If you cannot agree to this (for example, your employer's policy forbids it),
please say so in the pull request instead of submitting it — a bug report or
a feature request without code is still welcome and needs no agreement.

Until this is wired into CI as an automated check, the maintainer confirms
agreement with each contributor manually before merging; a pull request
opened before that automation exists is not merged without this being
settled in the PR thread first.
