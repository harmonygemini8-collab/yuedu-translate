# 04 交互设计说明

> 文档编号：UX-001 ｜ 版本：v0.1 ｜ 状态：待评审

## 1. 入口

| 入口 | 行为 |
|---|---|
| 工具栏图标 → 弹窗 | 主要入口，查看状态并执行翻译操作 |
| 右键菜单“阅渡：翻译此页 / 显示原文” | 快速切换 |
| 快捷键（建议 `Alt+Y`） | 翻译 / 恢复原文切换，可在 Chrome 快捷键设置中修改 |

快捷键是否与常用软件冲突，在技术验证阶段确认。

## 2. 扩展弹窗

当前实现：

```text
┌──────────────────────────────┐
│ 阅渡 Yuedu Translate      ⚙  │
├──────────────────────────────┤
│ 未登录            [登录/注册] │  ← 账号行；已登录时显示邮箱，Pro 用主题色
├──────────────────────────────┤
│ 此服务免费，登录后即可使用     │  ← 当前服务的数据去向，或缺什么（登录 / VIP）
│                               │     后接剩余额度
├──────────────────────────────┤
│ 翻译服务                      │  ← 标签在上，控件占满整行
│ [🟣 Qwen3-8B（免费）      ▾] │  ← 三组：免费·无需登录 / 免费·需登录 / VIP
│ 目标语言                      │     每行带服务商 logo
│ [简体中文                 ▾] │
│ 已翻译 16 段 · 失败 1 段       │
│ [▤] [        翻译        ]    │  ← 左侧开关：双语对照 / 仅译文，悬停提示当前状态
│ [停止]          [显示原文]     │
│ [重试失败段落]                 │
├──────────────────────────────┤
│ 快捷键 Alt+Y · 右键菜单  隐私说明│
└──────────────────────────────┘
```

- **显示模式开关**（0.3.5）：「翻译」按钮左侧一个方形开关。浅绿底、两组线条为「双语对照」（默认）；深绿实心、一组线条为「仅译文」。悬停（或键盘聚焦）出现深色提示：「当前为双语对照，点击切换为仅译文」。选择保存在设置中，已翻译的页面立即切换，不需要重新翻译。「仅译文」只收起**已有译文**的段落，正在翻译或失败的段落仍显示原文，不会出现空白。
- 进度以“已发现的段落”为基数；动态页面会新增段落，不显示误导性的固定百分比。
- 当前构建不可用的服务只置灰，不附加说明文字（保持简洁）。
- **「翻译范围」已移除**（0.3.4）：一律整页。可选的正文模式会静默漏掉菜单、标签页和表格里的文字，比多翻一点更糟；两种模式仍保留在提取器中，见 `src/shared/settings.ts` 的 `SCOPES`。
- **账号行的按钮打开设置页的账号区，不在弹窗内登录。** 登录要从邮件里读验证码，而浏览器弹窗一失焦就关闭，填了一半的表单会连同弹窗一起消失；设置页是标签页，扛得住这趟来回。
- **两个控件标签在上、宽度占满。** 原先标签与控件同行、控件限宽 62%（防止马来语等长标签把控件挤出边界），结果每个控件宽度都不同，在 300px 的弹窗里窄到读不全语言名。
- **点「翻译」后弹窗自动关闭（2026-10-20）。** 翻译的进度在页面上看得见（译文逐段出现），弹窗留着只会挡住页面；页面不能翻译（被禁用的网站、不能运行的页面）时弹窗保持打开，原因就写在里面。停止、显示原文、重试失败段落、朗读译文也一样：操作成功就关闭，效果都在页面上看。
- 设计取舍见 [12 设计思路归档](./12-design-rationale.md)。

## 3. 设置页

| 分组 | 内容 |
|---|---|
| 翻译 | 翻译服务（附一句说明）、目标语言（44 种，分地区分组并可搜索，见 [12 §3.3](./12-design-rationale.md)）、界面语言（跟随浏览器/简中/繁中/英/日/越/马来/阿拉伯） |
| 服务器连接 | 开发访问令牌、测试连接、各服务可用性与本月用量（仅连接后端的构建） |
| 译文样式 | 字号比例、颜色、与原文间距、左侧标识线 |
| 站点 | 本地禁用站点列表 |
| 数据 | 清理本地缓存、隐私与第三方处理方说明 |
| 账号 | 登录状态、额度、退出登录（MVP-A） |
| 划词翻译 | 开关：选中网页文字后是否显示查词按钮 |
| 关于 | 版本号、官网链接、联系邮箱 |

“自动翻译此网站”当初后置，因为需要持久站点权限和更明确的上传授权；2026-10-02 实现时正是按此处理——设置页逐个添加网站，添加时浏览器单独询问该站权限，移除即收回。

## 4. 页面内状态

```text
未开始 → 识别正文 → 翻译中 → 完成 / 部分失败
                        ↓
                       停止
任意状态 → 恢复原文 → 未开始
```

| 状态 | 页面表现 |
|---|---|
| 翻译中 | 段落下方显示轻量加载占位 |
| 成功 | 显示译文，样式与原文一致 |
| 单段失败 | 显示简短错误与“重试”入口，不影响其他段落 |
| 停止 | 保留已显示译文，不再出现新的加载占位 |
| 恢复原文 | 移除全部译文、占位与标记 |

## 4.1.1 悬浮按钮（触屏设备，0.3.5）

手机没有快捷键、没有右键菜单、没有悬停，工具栏弹窗又难打开，所以页面里自带一个入口：

```text
              ┌──────────┐
              │ 朗读译文 │   ← 展开后才出现，按钮大小适合手指（≥44px）
              ├──────────┤
              │  仅译文  │   ← 写的是「点一下会切到的模式」
              ├──────────┤
              │ 本页隐藏 │
              └──────────┘
                  (↺)        ← 主按钮：没翻译时点一下翻译；翻译后点一下显示原文
                  (⋯)        ← 小按钮：展开 / 收起上面三项
```

- **只在触屏设备上默认出现**（设置页「悬浮按钮」：仅触屏设备显示 / 总是显示 / 不显示）。电脑上不出现，因为有快捷键和右键菜单。
- 可以**上下拖动**，位置记住；点别处收起菜单；「本页隐藏」只管当前页面，刷新后回来。
- 翻译中主按钮显示转圈；图标表示「点一下会发生什么」：翻译图标 = 点了就翻译，回退箭头 = 点了就显示原文。
- 朗读项在有译文之后才出现，朗读中变为「停止朗读」。
- 悬浮按钮和查词一样，依赖内容脚本已在页面里：**没有「所有网站」授权时，只有点过翻译的页面才有**。触屏上弹窗里会出现「在所有网站启用」按钮，一次授权即可。
- 弹窗里的显示模式开关在触屏上直接显示当前模式的文字，因为触屏看不到悬停提示。

## 4.1.2 朗读时页面自动跟随

朗读时页面跟着往下滚，保证读完**这一篇**：

- 读到哪一段，就把那一段滚到屏幕上方约三成的位置（已经在屏幕中间一带的不动，避免来回晃）。
- 已翻译的段落都读完后，页面再往下滚一屏（约 85%），让后面的段落进入视野、被翻译，然后接着读。
- **到文章末尾就停，不读到页面底部。** 网页往下常常是另一篇文章（相关推荐、无限滚动），读到底部会读进别的文章，还会把它们也翻译掉、白白消耗额度。文章末尾是用开始朗读时屏幕上那一段所在的 `article`（没有就是 `main`）来界定的；最后一次滚动只滚到该容器的底边，不多滚。
- 读者自己滚动、滚轮或按键后，4 秒内朗读不再移动页面，免得和手抢；这段时间里朗读照常继续。
- **息屏后继续读（真机日志确认的事实）**：
  - 屏幕灭了页面进入后台，**浏览器会立刻取消系统自带的语音**（日志里 `page hidden` 之后 20 毫秒出现 `utterance error: interrupted`），后台里系统语音也启动不了（`synthesis-failed`）。这是浏览器的行为，页面代码无法绕过；它不是页面被冻结。
  - **服务器的神经语音是真正的音频**（用 `<audio>` 元素播放），和息屏时继续放歌是同一类东西，息屏后照常播放。所以**息屏朗读需要登录**（服务器语音用免费每日额度，未登录或额度用完时退回系统语音）。
  - **未登录、用系统语音时**：息屏后朗读停在被打断的那一句，**不再往下硬读**；亮屏后把被打断的那一句重读一遍，再接着往下，不丢内容。后台里也不再自动滚动。
  - **为让息屏读得完整篇**：触屏设备开始朗读时，会先把这篇文章（最多约 2 万字）剩下的部分提前翻译好。否则息屏后页面不再滚动，也就不再触发翻译，朗读会在已翻译的最后一段结束。
- **保活手段**：朗读期间页面向系统注册媒体会话（锁屏通知里出现标题和暂停键，按暂停即停止朗读），并循环播放一段几乎听不见的音频。它们对服务器声音有帮助；对系统语音**没有用**，系统语音息屏必被取消。浏览器拒绝时（例如没有用户手势）这些都静默跳过。
- **限制**：页面没有 `article` / `main` 标记时找不到文章末尾，不会自动滚动，只读已经翻译出来的部分；`main` 里并排放了好几篇文章的信息流页面同样不自动滚动。

## 4.2 划词查词

**哪些页面有查词：**查词按钮由内容脚本画出，所以只在内容脚本已经在的页面上出现——点过「翻译」的这一次页面加载，或已授权的「自动翻译」网站。**其他页面、刷新之后都没有**，这是浏览器的权限模型决定的：没有主机权限就不能在用户点击前把脚本放进页面。想在所有网页上都能查词，要在设置页打开「允许在所有网站上运行」；设置页的查词开关下面在未开启时会提示，并有「在所有网站启用」按钮。开启后只对**之后打开或刷新的页面**生效。

选中文字后，在选区下方出现一个「查词」小按钮；**选中本身不会触发翻译**。把鼠标停在按钮上约 0.15 秒，气泡就自动打开，不需要点击（点击仍然有效）；鼠标只是路过则不触发。**触屏设备没有悬停，只靠点一下**；触屏点击时浏览器会先模拟一次「鼠标移上去」，代码里在没有悬停能力的设备上忽略它，并在点击时取消悬停计时，避免同一个词查两次。
这样复制文字、反复拖选、边读边划都不会被打断，也不会在用户没有意图时消耗额度。

点击后按选中内容分两种结果：

| 选中内容 | 气泡内容 |
|---|---|
| 单个词 | 顶部：词、音标、🔊；中部：词性释义，每条「词性（强调色斜体）+ 释义」；底部：一个浅绿底的圆角框，放此处的译文（加粗）与「在这句话里」的解释 |
| 一段话 | 译文 |

气泡内容**逐字出现**（约 1 秒打完，长短不论）：未打出的文字仍占着最终的位置，只是不可见，所以气泡不会边打边变高或重新换行。系统设置了「减少动态效果」时直接整段显示。

版式参考沉浸式翻译的查词卡（词头、释义列表、底部提示框），配色沿用本扩展的深绿主题；页面深色模式下底色跟随系统。

音标、释义和上下文解释由大模型给出，属 VIP 权益，请求计入 VIP 标准额度；
未登录、非 VIP 或额度用尽时自动降级为普通译文，并在气泡底部说明原因，不报错。
单词旁 🔊 的朗读用浏览器内置的语音合成（`speechSynthesis`），本地发声，不联网、不需要新权限。弹窗里的「朗读译文」另有规则：本地有自然语音就用本地，没有且已登录才用服务器语音，见 [03 FR-16](./03-prd.md) 与 [07 §1](./07-security-privacy.md)。

气泡在 Shadow DOM 中渲染，页面样式无法影响它；所有文字用 `textContent` 写入。
按 Esc 或点击别处关闭。输入框、文本域和可编辑区域内的选中不触发——那是在写字，不是在读。

## 5. 错误文案（草案）

| 场景 | 文案 |
|---|---|
| 受限页面 | 此页面受浏览器限制，阅渡无法在此运行。 |
| 未登录（免费引擎） | 此服务免费，登录后即可使用。——免费但需账号的引擎不该提示得像付费墙 |
| 未登录（VIP 引擎） | 此服务需要登录，请在设置中登录。 |
| 额度不足 | 本月翻译额度已用完。 |
| 限流 / 网络被限制 | 请求过多或当前网络被翻译服务限制，请稍后再试或切换翻译服务。 |
| 服务未开通 | 所选翻译服务尚未开通。 |
| 网络失败 | 网络连接失败，可点击重试。 |
| 服务故障 | 翻译服务暂时不可用，请稍后重试。 |

## 6. 视觉原则

**扩展图标：**青绿→蓝色渐变圆角方块；上方白色横条代表原文，下方黄色横条加左侧竖线代表“紧挨原文的译文”，与页面中译文的样式呼应。图标由 `scripts/generate-icons.mjs` 用几何图形生成（`npm run icons`），矢量源 `doc/assets/icon.svg`，不使用字体字形，避免字体授权问题。设计思路见 [12 设计思路归档 §2](./12-design-rationale.md)。

- 界面简洁、简约：只保留完成任务所需的信息，不堆叠说明文字；

- 译文默认与原文样式一致（字体、字号、粗细、颜色、行高均继承原段落），左侧保留一条同色细竖线作为译文标识；设置页可自定义字号、颜色、标识线；
- 不改变原文元素尺寸与位置之外的样式；
- 扩展 UI 样式与网页隔离，避免相互污染；
- 支持网页暗色背景下的可读性（使用 `currentColor` 派生或可配置颜色）。
