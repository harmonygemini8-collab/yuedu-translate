# 22 视觉识别规范（VI 手册）

> 文档编号：VI-001 ｜ 版本：v0.1 ｜ 状态：现状盘点 + 规则；§6 中第 1–4、6 项已于 2026-10-14 完成，第 5 项是有意的例外  
> 用途：规定阅渡在扩展弹窗、设置页、页面内气泡、官网、商店图片上用什么颜色、字体和形状。新增或修改界面前先查这里；要加新颜色，先改本文再改代码。  
> 术语：企业形象识别（CI）包含理念、行为和视觉三部分，其中管颜色、字体、图标的叫视觉识别（VI）。本文只做 VI。

## 1. 原则

1. **安静、克制**：阅读工具，界面不抢正文。主色只用在需要点击或需要注意的地方。
2. **译文跟随页面**：页面里的译文默认继承原文的字体、字号、颜色，不套品牌色（用户可在设置里改）。品牌色只出现在扩展自己的界面里。
3. **一个主色**：扩展内只有深绿一个强调色，状态色（错误、警告）只表示状态。
4. **渐变只用于宣传**：青到蓝的渐变用于商店图、官网首屏和视频，不进入扩展界面。

## 2. 色彩

### 2.0 令牌与 CSS 变量

文中的令牌名是规范用语；代码里用下面的 CSS 变量，各样式文件顶部集中定义，正文里一律写 `var(--…)`，不再写死色值。

| 令牌 | 扩展（弹窗 / 设置页 / 气泡） | 官网 |
|---|---|---|
| brand | `--accent` | `--accent` |
| brand-hover | `--accent-hover`（弹窗） | — |
| brand-ink | `--accent-ink`（弹窗） | — |
| brand-tint | 弹窗 `--accent-tint`，设置页 `--accent-tint`（深色下另有取值） | `--accent-tint` |
| brand-tint-hover | `--accent-tint-hover`（弹窗） | — |
| ink | `--ink`（弹窗） | `--ink` |
| muted | `--muted` | `--muted` |
| border | `--border` | `--line`（官网保留较浅的灰，见 §6 第 4 项） |
| error | `--error` | `--error` |
| warn | `--warn-bg` / `--warn-ink` | — |

页面内查词气泡在 Shadow DOM 里，页面和扩展样式都进不去，所以它在自己的 `.layer` 上另定义一份（`--accent`、`--accent-wash`、`--muted`、`--error`），改色时要同步改。官网另有 `--text-2`（`#4b5563`）、`--text-3`（`#374151`）两级正文灰和 `--accent-edge`（`#bcd8ce`，浅绿卡片的边框）。

### 2.1 品牌色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `brand` 阅渡绿 | `#2f6f5e` | 主按钮、链接、选中态、账号 Pro 标识、查词按钮、气泡里的词性与小标题 |
| `brand-hover` | `#285f50` | 主按钮、实心开关的悬停态 |
| `brand-ink` | `#1f5245` | 浅绿底上的文字（如引擎说明条） |
| `brand-tint` | `#e7f3ef` | 浅绿底：说明条、双语对照开关、选中项底色 |
| `brand-tint-hover` | `#d6eae3` | 浅绿底的悬停态 |

### 2.2 中性色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `ink` | `#1f2937` | 官网正文；深色提示框底色 |
| `muted` | `#6b7280` | 次要文字、标签、音标 |
| `border` | `#d9dde3` | 弹窗、控件边框与分隔线 |
| `surface` | `#ffffff` | 卡片、弹窗、气泡底色 |
| `surface-soft` | `#f7f8fa` | 设置页侧栏底色 |
| `mail-line` | `#e5e7eb` | 验证码邮件里的分隔线（比 `border` 浅一档，邮件是白底大面积留白，线要更轻） |
| `mail-code-bg` | `#eef2f6` | 验证码邮件里验证码的灰底块 |

深色模式：弹窗与气泡用系统的 `Canvas` / `CanvasText`，随浏览器深浅切换；设置页有自己的深色变量，见 `src/options/options.css` 的 `prefers-color-scheme: dark`。品牌色在深色下不变。

### 2.3 状态色

| 令牌 | 色值 | 用途 |
|---|---|---|
| `error` | `#b42318` | 错误文字 |
| `warn-bg` / `warn-ink` | `#fff4d6` / `#7a5a00` | 警告说明条（如需要登录、额度不足） |

### 2.4 宣传渐变（仅商店图、官网、视频）

`#14b8a6` → `#2563eb`，135°。与图标的青蓝同源。

## 3. 字体

- 中文与西文统一用系统字体：`system-ui, "Microsoft YaHei", sans-serif`；阿拉伯语回退 `"Noto Sans Arabic"`。不加载网络字体。
- 弹窗基准 13px；气泡正文 14px，词头 19px 加粗；设置页以 14px 为基准。
- 官网英文示例文章用 `"Times New Roman", serif`（因为它覆盖越南语声调，Georgia 不覆盖）；这只是示例内容的字体，不是界面字体。

## 4. 形状与间距

| 元素 | 圆角 |
|---|---|
| 按钮、下拉框 | 6px |
| 浅绿提示框、查词释义框 | 8px |
| 查词气泡、官网卡片 | 12px |
| 账号行的小按钮、胶囊标签 | 999px |

- 弹窗宽度固定 300px，左右内边距 14px。
- 图标线宽 2px，圆头，用 `currentColor`，跟随文字颜色。
- 提示（tooltip）：`#1f2937` 底、白字、12px、圆角 6px，带小三角。

## 5. 图标与名称

- 应用图标矢量源：`doc/assets/icon.svg`；商店图标 `release/assets/store-icon-128x128.png`（图形 96×96，四周各留 16px 透明边距）。
- 中文名「阅渡」，英文展示名 Yuedu Translate，二者并排时中文在前，英文用 `muted` 色小一号。
- 品牌名称使用边界见 [12 §2](./12-design-rationale.md)。

## 7. 使用规则

1. 新界面只用 §2 里的令牌；要新颜色先改本文并写明用途。
2. 状态色不当装饰色用。绿色只表示"品牌 / 可操作"，不用来表示"成功"以外的含义。
3. 译文颜色由用户设置决定，代码里不给译文硬编码品牌色。
4. 宣传图可以用渐变，但图里的弹窗必须是真实弹窗（`npm run store-assets` 用真实的 `popup.html` 渲染）。
5. 改完颜色后同步：弹窗、设置页、气泡、官网、商店截图（`npm run store-assets`）。
