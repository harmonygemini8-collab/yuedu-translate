# 11 翻译服务与费用控制

> 文档编号：SVC-001 ｜ 版本：v0.2 ｜ 状态：已上线  
> 价格查询日期：2026-10-01，以服务商官网最新价格为准。

## 1. 产品方案

用户在扩展弹窗或设置页选择翻译服务：

| 选项 | 服务 | 调用方式 | 定位 | 说明 |
|---|---|---|---|---|
| 谷歌翻译（免费，默认） | 谷歌网页翻译免费接口 `translate.googleapis.com/translate_a/single` | 用户浏览器直连，不经过阅渡服务器 | 免费档 | 无需密钥和服务器；非官方接口，不保证稳定 |
| 微软翻译（免费额度） | Azure AI Translator v3，**F0 免费定价层** | 经阅渡服务器 | 免费档 | 官方 API；每月 200 万字符，用完即停、不扣费 |
| Qwen3-8B（免费） | 硅基流动托管的 `Qwen/Qwen3-8B` | 经阅渡服务器 | 免费档 | 开源小模型，平台单价 ¥0；整批 JSON 翻译 |
| GLM-4-9B（免费） | 硅基流动托管的 `THUDM/GLM-4-9B-0414` | 经阅渡服务器 | 免费档 | 同上 |
| 混元翻译 MT-7B（免费） | 硅基流动托管的 `tencent/Hunyuan-MT-7B` | 经阅渡服务器 | 免费档 | **翻译专用模型**，不走 JSON 批量：逐段请求、直接取回译文，长页面较慢 |
| 谷歌翻译（官方 API） | Google Cloud Translation - Basic（v2，NMT） | 经阅渡服务器 | 付费档 | 稳定；平台每月字符上限，默认不超出 Google 免费额度 |
| OpenAI（付费） | OpenAI Responses API，默认 `gpt-6-luna` | 经阅渡服务器 | 付费档 | 大模型翻译，按用量计费 |

免费档内部还有一条分界：**只有「谷歌翻译（免费）」不需要账号**，它由浏览器直连。其余四个免费引擎都经阅渡服务器，服务器要按用户扣减每日额度，所以必须登录。界面上因此把免费档分成「免费 · 无需登录」与「免费 · 需登录」两组（见 [04 §服务选择](./04-interaction-design.md)），不再笼统写「免费」。

**语言支持：**目标语言共 45 种，含粵語 `yue`（取舍见 [12 §3.3](./12-design-rationale.md)）。

| 服务 | 覆盖 | 备注 |
|---|---|---|
| 谷歌翻译（免费 / 官方 API） | 免费：全部 45 种；官方 API：除粵語外 44 种 | 免费接口直接接受本项目使用的语言代码；Cloud Translation v2 没有 `pt-BR`（并入 `pt`），希伯来语、菲律宾语、挪威语仍用旧式 `iw`/`tl`/`no` |
| 微软翻译 | 全部 45 种 | `zh-Hans`/`zh-Hant`；注意微软的 `pt` 指巴西葡语，欧洲葡语是 `pt-PT` |
| 硅基流动三款（Qwen3-8B / GLM-4-9B / 混元 MT-7B） | 全部 45 种 | 与 OpenAI 同样以语言英文名下达指令；小模型对冷门语种的质量弱于大模型，尚未逐语种实测 |
| OpenAI（两档） | 全部 45 种 | 以语言英文名下达指令，避免模型选错变体 |

**粵語（`yue`，0.3.5 新增）：** 谷歌免费接口 2026-10 实测可直接译出口语粤语（如「資本喺世界各地流動嘅方式」）；微软用 `yue`；LLM 类引擎以「口语香港粤语，繁体字」下达指令；官方 Cloud Translation 基础模型是否支持未核实，故该档暂不开放。朗读时目标语言 `yue` 映射为浏览器语音的 `zh-HK`，Edge 自带 HiuGaai 等 Natural 粤语声音。已是中文的文字不会再译成粤语（引擎无法区分普通话与粤语文本）。

各服务的语言代码写法不同，映射表放在各自的 `server/providers/*.ts`（免费谷歌在 `src/background/google-free.ts`，无需映射）。

不支持的组合在界面中置灰，服务器返回 400。支持表定义在 `src/shared/settings.ts` 的 `ENGINE_LANGUAGES`。

**当前状态：**账号与按用户额度已上线（[15](./15-paid-plan-design.md) P1）：付费档需登录且账号为 Pro，由服务器校验；VIP 目前为邀请试用，支付（P2）尚未接入。运维令牌 `YILIN_DEV_TOKEN` 不受用户额度限制，仅用于运维接口。

## 2. 免费谷歌翻译的取舍（ADR-13）

免费档使用谷歌网页翻译背后的免费接口，由**用户浏览器直接调用**。不放在阅渡服务器上调用，因为所有用户经同一服务器 IP 请求会很快被谷歌限流或封禁。

| 风险 | 说明 | 应对 |
|---|---|---|
| 条款风险 | 接口未对外公开授权，谷歌服务条款限制以非官方方式自动化访问其服务；收费产品被追究的可能性高于个人工具（非法律意见） | 产品负责人已知悉并接受；正式上架前再做法律评估 |
| 稳定性 | 无服务保障，接口格式或限制可能随时变化 | 解析时严格校验返回格式；失败时提示用户切换到官方 API 或 OpenAI；后续可增加自动切换 |
| 限流 | 单个用户短时间请求过多可能被临时限制 | 每批合并为一次请求；扩展端并发上限 3 批 |
| 网络可达性 | 中国大陆网络通常无法直接访问 Google，免费档在这些网络下不可用 | 设置页提示“需要能访问 Google 的网络”；付费档经服务器调用不受用户网络限制（取决于服务器部署地区） |
| 隐私 | 段落文本直接发给 Google，不经过阅渡服务器 | 隐私说明如实告知；请求不携带 Cookie（`credentials: 'omit'`） |

实现要点（`src/background/google-free.ts`）：

- 一批段落用换行拼接为一次 POST 请求（段落文本已规范化，不含换行）；返回行数不一致时退回逐段请求（并发 4）。
- HTTP 429/503 视为限流，网络失败视为 `NETWORK`，格式异常视为 `PROVIDER_UNAVAILABLE`。
- 该接口返回 `Access-Control-Allow-Origin: *`，因此扩展无需声明主机权限即可从 Service Worker 请求（见 [07 §2](./07-security-privacy.md)）。
- **实测记录（2026-10-01）：**开发机直连无法访问 Google；经本机代理（共享出口 IP）请求，GET 与 POST 均返回 **HTTP 429**，页面提示“your computer or network may be sending automated queries”。说明代理/VPN 的共享出口 IP 很容易被谷歌拒绝，**很多大陆用户即使翻墙也可能用不了免费档**。返回格式尚未在正常网络下验证，自动化测试基于公开资料中的格式。
- 429 在扩展中提示为“请求过多或当前网络被翻译服务限制，请稍后再试或切换翻译服务”。
- **实测记录（2026-10-01，用户 Chrome + 代理）：**谷歌不返回 429，而是把请求 302 跳转到人机验证页 `www.google.com/sorry/…`。浏览器跟随跳转后因跨域被拦截，控制台出现 CORS 报错、页面显示为“网络连接失败”。现以 `redirect: 'manual'` 发起请求，遇到跳转即按限流（`RATE_LIMITED`）处理，不再跟随跳转。用户遇到此提示应切换翻译服务（如 VIP 的 OpenAI 或微软免费额度），或更换网络出口后重试。

## 2.1 官方免费额度：微软翻译（ADR-14）

| 项目 | 微软翻译 F0 |
|---|---|
| 免费额度 | 每月 200 万字符 |
| 超额行为 | 服务暂停至下个订阅月，返回错误码 `403001`，不扣费 |
| 开通条件 | Azure 账号，创建 Translator 资源并选择 **F0** 定价层 |
| 中文代码 | `zh-Hans` / `zh-Hant`（注意其 `pt` 指巴西葡语，欧洲葡语为 `pt-PT`） |
| 接口 | `POST api.cognitive.microsofttranslator.com/translate?api-version=3.0` |

实现要点：

- 按“免费档”展示，经服务器调用，密钥只在服务器上。
- 服务器按服务记录每月字符数，默认上限等于免费额度（可配置），避免超出；若服务商先返回“额度用完”，服务器立即把该服务本月标记为已用尽，后续请求直接返回 `QUOTA_EXCEEDED`，不再请求服务商，其他服务不受影响。
- 字符计数口径与服务商可能略有差异，以服务商返回的“额度用完”为准。

> DeepL API Free 曾在此处并列（ADR-14），已于 2026-10-08 移除，原因见 [10 ADR-24](./10-risks-and-decisions.md)。

**全平台免费额度合计**：谷歌官方 50 万 + 微软 200 万 ≈ 每月 250 万字符（约 140 篇 3000 词长文），仍然是所有用户共用。用户量上来后，免费档需要配合单用户每日额度（待账号体系）或失败时切换的策略。

## 2.2 朗读：Azure AI Speech（0.3.5）

「朗读译文」默认用浏览器自带语音。浏览器没有自然语音（Chrome）且用户已登录时，改用阅渡服务器转发的 Azure AI Speech 神经语音，和 Edge 自带的是同一批。

| 项 | 内容 |
|---|---|
| 接口 | `POST /v1/tts`，请求 `{ lang, text }`，`text` ≤ 500 字符；返回 `audio/mpeg`，输出格式 24 kHz 48 kbps 单声道 MP3 |
| 计费与额度 | 服务器内部记作 `azure-tts`：计入用户的「今日免费额度」（与免费翻译共用）和平台每月字符上限（默认 40 万，免费层 50 万） |
| 声音 | 每种目标语言一个神经语音，见 `server/providers/azure-speech.ts`；表里没有的语言不提供，扩展退回本地语音。粵語用 `zh-HK-HiuMaanNeural` |
| 不用时 | 不填 `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` 则整项关闭，扩展只用本地语音 |
| 申请步骤 | [16 §C2](./16-server-deployment.md) |

声音名称是按微软的命名习惯写入的，**上线前需在真实资源上逐个听一遍**：名称不存在时微软会返回 400，扩展会退回本地语音。

## 3. 价格与成本（2026-10-01）

| 服务 | 价格 | 免费额度 |
|---|---|---|
| Microsoft Translator（S1 标准层，参考） | 按量计费（以 Azure 价格页为准） | F0 免费层每月 200 万字符 |
| 硅基流动 Qwen3-8B / GLM-4-9B / 混元 MT-7B | **¥0**（平台标注「免费」，2026-10-12 核实） | 不按额度封顶，而是按**账户级**速率上限限制；清单可能变动，需定期复核 |
| Google Cloud Translation（NMT） | 每 100 万字符 $20 | 每月前 50 万字符（以每月 $10 抵扣形式，平台所有用户共用） |
| OpenAI `gpt-6-luna` | 输入 $0.10、输出 $0.50 / 100 万 token | 无 |
| OpenAI `gpt-6.1-sol`（可选高质量） | 输入 $2、输出 $10 / 100 万 token | 无 |

**按代码里的估算公式折算**（`server/providers/openai.ts`：输入 ≈ 字符数 ÷ 3 加每请求 400 token 提示词开销，输出 ≈ 字符数 ÷ 2，每批最多 4000 字符）：

| 翻译 100 万字符 | 输入 token | 输出 token | 成本 |
|---|---|---|---|
| `gpt-6-luna`（标准） | 43 万 | 50 万 | **≈ $0.29** |
| `gpt-6.1-sol`（高质量） | 43 万 | 50 万 | **≈ $5.87** |
| Google Cloud Translation | — | — | $20（超出平台免费额度后） |

注意**输出比输入多**（译文长于原文的 token 数），而输出单价是输入的 5 倍，所以成本几乎由输出决定。早先"标准 $0.2、高质量 $4"的估算未计提示词开销与输入输出比例，低估约 40%，已按上表更正。

**启示：**Google 免费额度对全平台而言很小（3000 词长文约 1.8 万字符，每月约 27 篇）。正式定价前需用真实用量重新测算（见 06 文档 §6）。

## 4. 费用控制（后端实现）

| 机制 | 默认值 | 配置项 |
|---|---|---|
| 平台月度费用上限 | $10 | `YILIN_MONTHLY_BUDGET_USD` |
| Google 官方 API 月度字符上限 | 500,000（保持在免费额度内） | `GOOGLE_MONTHLY_CHAR_LIMIT` |
| 微软翻译月度字符上限 | 2,000,000（F0 免费额度） | `MICROSOFT_MONTHLY_CHAR_LIMIT` |
| 每分钟请求数 | 60 | `YILIN_REQUESTS_PER_MINUTE` |
| 单批上限 | 16 段 / 4000 字符 / 单段 2000 字符 | 代码常量 |
| 上游超时 | 25 秒 | 代码常量 |

规则：

1. 请求前按**保守估算**预留费用，并发请求不会超出上限；完成后按实际用量结算（OpenAI 使用返回的 token 数，Google 按字符数）。
2. 上游明确返回 HTTP 错误视为未处理，不计费；超时或响应异常可能已被计费，按估算计入。
3. 超出上限返回 `QUOTA_EXCEEDED`，扩展提示“本月翻译额度已用完”。
4. 用量（不含正文）保存在 `server/data/usage.json`，每月自动清零。
5. 若更换 OpenAI 模型，必须同步修改 `OPENAI_INPUT_PRICE_PER_M` / `OPENAI_OUTPUT_PRICE_PER_M`，否则费用统计不准。

服务商控制台也应设置预算提醒或用量上限，作为第二道防线。

## 5. 隐私处理

- 只发送段落文本、目标语言；不发送网址、Cookie、表单内容。
- OpenAI 请求设置 `store: false`；系统提示要求模型忽略网页文本中的指令，只做翻译；输出使用 JSON Schema 结构化格式，只接受请求过的段落 ID。
- 服务器日志只记录方法、路径、状态码、耗时、服务和字符数。
- 硅基流动的免费模型按其条款可能将输入输出用于改进服务，比付费接口的保留承诺弱；这一点在官网隐私政策的第三方清单中已列出该服务，选择这三个引擎的用户等于接受该政策。
- 服务商自身的数据保留政策需在正式隐私政策中如实披露。

## 6. 密钥申请步骤

### 6.1 Google Cloud Translation

1. 登录 Google Cloud 控制台，新建项目（如 `yuedu-translate`）。
2. 为项目关联结算账号（启用该 API 需要结算账号；免费额度内不产生费用）。
3. 在“API 和服务”中启用 **Cloud Translation API**。
4. 在“凭据”中创建 **API 密钥**，并在密钥设置中**限制为仅可调用 Cloud Translation API**。
5. 在“结算 → 预算和提醒”中设置预算提醒（例如 $1）。注意 Google 的预算提醒只通知、不会自动停止扣费，硬性上限由阅渡服务器的字符上限保证。

### 6.2 Microsoft Translator（F0 免费层）

1. 登录 Azure 门户，创建 **Translator**（Azure AI Translator）资源。
2. 定价层选择 **F0（Free）**——这是不会扣费的关键；每个订阅通常只能有一个 F0 Translator 资源。
3. 记下资源的“区域”（如 `eastasia`）；若选择“Global”则区域可留空。
4. 在资源的“密钥和终结点”中复制 **密钥 1**。
5. 填入 `MICROSOFT_TRANSLATOR_KEY` 与 `MICROSOFT_TRANSLATOR_REGION`。

### 6.3 OpenAI

1. 登录 OpenAI Platform，创建项目（如 `yuedu-translate`）。
2. 在结算页添加付款方式并充值少量额度。
3. 在项目中创建 **API Key**。
4. 在用量限制页设置每月上限（例如 $10）和提醒。

### 6.5 SiliconFlow 硅基流动（三个免费模型共用一个密钥）

Qwen3-8B、GLM-4-9B、混元 MT-7B 都托管在硅基流动，**一个密钥同时开通三个**，无需分别申请。

1. 注册并登录 <https://cloud.siliconflow.cn/>（支持手机号、邮箱、微信）。
2. 在「用户中心 → 实名认证」完成实名（见下方说明）。
3. 打开 <https://cloud.siliconflow.cn/account/ak>，点击「新建 API 密钥」。
4. 填入 `SILICONFLOW_API_KEY`。三个引擎共用这一个值。

接口兼容 OpenAI 的 `chat/completions`，base URL `https://api.siliconflow.cn/v1`；结构化输出用 `response_format={"type":"json_object"}`（不支持严格 json_schema，所以形状写在提示词里、解析后逐字段校验）。

**三条必须知道的约束：**

- **限速按账户算，不按密钥算。** 官方原文：「Rate Limit 是在用户账户级别定义的，而不是密钥（API key）维度」。我们用一个账号代理全部用户，等于所有人共享一份配额 —— 这是用户增长后最先撞到的天花板，不是费用问题。免费模型的速率上限是固定值，具体数字需登录模型广场查看。
- **实名认证的说法在官方两处互相矛盾。** [Rate Limits 页](https://docs.siliconflow.cn/docs/userguide/faqs/rate-limit-and-upgradation)写「实名认证后使用全部的免费模型」；[实名认证 FAQ](https://docs.siliconflow.cn/docs/userguide/faqs/authentication) 却只说未实名会导致无法「账户充值」和「开具发票」，没提免费模型。按前者准备更稳妥。个人认证接受身份证、回乡证、台胞证、港澳/台湾居民居住证、外国人永久居留证，均需用支付宝 App 扫码刷脸；企业认证需要中国的统一社会信用代码，英国主体用不了。
- **模型清单会变。** 这三个模型 2026-10-12 核实为「免费」。小参数量开源模型被下架或转收费是常事，上线后需定期复核 <https://www.siliconflow.cn/pricing>。

### 6.4 填写到本地

```bash
cp server/.env.example server/.env   # Windows 可直接复制文件
```

编辑 `server/.env`，填入 `YILIN_DEV_TOKEN`（随机字符串）以及需要启用的服务密钥：`MICROSOFT_TRANSLATOR_KEY`（+ `MICROSOFT_TRANSLATOR_REGION`）、`SILICONFLOW_API_KEY`、`GOOGLE_TRANSLATE_API_KEY`、`OPENAI_API_KEY`。未填写的服务在扩展中显示为“尚未开通”。`server/.env` 已加入 `.gitignore`，**不要提交或在聊天中粘贴真实密钥**。

## 7. 本地运行

```bash
npm run server        # 启动后端 http://127.0.0.1:8787
npm run build:ext:local   # 构建连接本地后端的扩展到 dist/
```

在 Chrome 重新加载 `dist/` 扩展 → 设置页填写与 `YILIN_DEV_TOKEN` 相同的访问令牌 → 点击“测试连接” → 在弹窗中选择翻译服务。
