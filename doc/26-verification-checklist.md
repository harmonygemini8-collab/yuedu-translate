# 26 验证清单（0.4.01，2026-10-29）

> 这些改动都有单元测试，但**没有一项在真实网页和真实服务上完整跑过**。本表是需要你亲手确认的部分。每项写了怎么做、应该看到什么、出问题时把什么发回来。
>
> 准备：在 `Yilin-Translate` 目录运行 `npm run build:ext:prod`，到 `chrome://extensions` 点这个扩展的「重新加载」。开发版连的是线上接口，登录走官网。打开扩展详情，版本应显示 0.4.01。

勾选记号：☐ 未验证　☑ 通过　✗ 有问题（写在备注里）

## A. 论文阅读（最重要）

| ☐ | 做什么 | 应该看到 | 出问题发回来 |
|---|---|---|---|
| ☐ | 打开 `https://ar5iv.labs.arxiv.org/html/1810.04805`（BERT），按 Alt+Y，滚动读一遍 | 行内变量（如 *E*、*C*、*T*ᵢ）保留在译文里；`[CLS]`、`[SEP]`、BERT、GLUE 等不被翻、不跑到句尾；脚注数字是上标，不出现脚注全文；引用（Vaswani et al. 2017）不重复 | 截图 + 是哪一段 |
| ☐ | 同一页的表格（Table 1、Table 4） | 行名（`BiLSTM+ELMo+Attn`、`ESIM+GloVe`、`BERT`ᴮᴬˢᴱ）原样，不被翻成别的；单元格没有"原文 原文"的重复；表头 System、Dev、Test 译成中文 | 截图 |
| ☐ | 滚到 References | 每条只多出标题和刊物行的译文，作者、年份、编号不动；"Character-level" 译为"字符级"；"In TAC. NIST." 没有被翻成乱码 | 截图 |
| ☐ | `https://ar5iv.labs.arxiv.org/html/1706.03762`（Transformer），读 3.2 节 | 公式 *d*ₖ、√*d*ₖ 在句子里；"Figure 2"、"See Figure 2." 不被拆到译文之外；"Scaled Dot-Product Attention" 前后译法一致 | 截图 + 前后不一致的两处 |
| ☐ | 任选一篇别的 arXiv HTML 论文（你自己的专业） | 同上，不"一打开就是坏的" | 页面地址 + 截图 |

## C. 输入框翻译（默认关闭）

| ☐ | 做什么 | 应该看到 |
|---|---|---|
| ☐ | 设置 → 输入框翻译选「连按三个空格」，目标语言保持英语。在任意网页的输入框里打一句中文，连按三个空格 | 整框内容换成英文；输入框上方短暂出现状态提示；按 Ctrl+Z 能撤回成中文 |
| ☐ | 换成「Alt+Enter」，在输入框里选中半句中文，按 Alt+Enter | 只翻选中的半句 |
| ☐ | 在密码框里按三个空格 / Alt+Enter | 什么都不发生 |
| ☐ | 在 Gmail 或 Notion 这类富文本框里试一次 | 能翻、能撤回；**如果不行，记下是哪个网站** |
| ☐ | 用中文输入法打字，选词时按空格 | 不会被当成三连空格 |

## D. 引擎自动切换与语言校验

| ☐ | 做什么 | 应该看到 |
|---|---|---|
| ☐ | **不登录**账号，把翻译服务选成「微软翻译」，翻一页 | 页面仍然翻出来了（后台换成了谷歌免费）；设置里把「引擎失败时自动换用其他免费服务」关掉后再翻，应出现"请先登录"的提示 |
| ☐ | 想办法让谷歌免费被限流（连续翻很多长页）再观察 | 已登录时自动换微软；没有出现整页红色错误 |

## E. 译文缓存

| ☐ | 做什么 | 应该看到 |
|---|---|---|
| ☐ | 翻一个长页，记下大约用时；刷新，再翻同一页 | 第二次明显更快，译文几乎立即出现 |
| ☐ | 设置里点「清除缓存」，再翻 | 恢复到第一次的速度 |
| ☐ | 关掉「在本机缓存译文」，翻、刷新、再翻 | 每次都重新请求 |
| ☐ | 换目标语言再翻同一页 | 不会取到旧语言的译文 |

## F. 自带密钥

| ☐ | 做什么 | 应该看到 |
|---|---|---|
| ☐ | 选「自带密钥」，地址 `https://api.openai.com/v1`，填模型名和密钥，点「测试连接」 | 浏览器弹出权限提示，允许后显示"连接成功" |
| ☐ | 用它翻一页论文 | 公式变量、`[CLS]` 这类没有被你的模型弄丢；若出现 `[[1]]`、`[[T2]]` 这样的字样漏在译文里，**截图发回来** |
| ☐ | 选一个英文单词查词 | 有音标、释义、「在这句话里」的解释（不需要 VIP）；弹窗里没有"升级 VIP"的提示 |
| ☐ | 在已登录 VIP 的状态下，选「自带密钥」，点朗读 | 是浏览器自带的声音，不是服务器的声音 |
| ☐ | （有的话）Claude：地址 `https://api.anthropic.com/v1`；Ollama：`http://localhost:11434/v1`，密钥留空 | 测试连接成功；失败时括号里的原话发回来 |
| ☐ | 故意把密钥填错一位，点测试 | 提示"密钥无效"，括号里有服务的原话 |

## G. 生词本

| ☐ | 做什么 | 应该看到 |
|---|---|---|
| ☐ | 选一个英文单词，点查词气泡里的 ☆ | 变成 ★，提示"已收藏"；再次选同一个词，一开始就是 ★ |
| ☐ | 设置 → 生词本 | 刚才的词在列表里，有释义、所在句子；搜索、删除可用；计数对 |
| ☐ | 导出 CSV，用 Excel / WPS 打开 | 中文不乱码；表头是 word, phonetic, translation, meanings, sentence, page, date |
| ☐ | 在一个有查询参数的页面（`?token=x`）上收藏 | 列表里的页面地址没有 `?` 之后的内容 |
| ☐ | 清空 | 先弹确认，确认后列表为空 |

## 发回来的格式

每个有问题的项写：**编号（如 A-3）+ 页面地址 + 截图 + 你期望的样子**。通过的不用逐项回复，说"其余通过"即可。如果某项你做不了（没有对应的服务），写"跳过"。

## 我这边仍没做的（不属于本次验证）

- 复习提醒（SRS）、一键导出 Anki 的 .apkg、跨设备同步。
- PDF。
- 表格里正常词的整格翻译只做了「名字保护」，没有做合并单元格等复杂表格的专门处理。
- 官网与商店的对外文案还没按学术方向改写（等你验证完再统一改）。
- 密钥轮换与仓库拆分（见 25 §2），需要你先换密钥。
