# 02 竞品分析与版本范围

> 文档编号：ANALYSIS-001 ｜ 版本：v0.1 ｜ 状态：待评审  
> 资料来源：沉浸式翻译官方介绍与使用文档（2026-10-01 查阅）。本次为公开资料调研，未安装竞品做交互实测。

## 1. 沉浸式翻译功能拆解

| 功能模块 | 主要能力 | 实现难点 | 阅渡规划 |
|---|---|---|---|
| 网页双语翻译 | 正文识别、段落对照、原文切换、全页翻译 | DOM 分段、排版、动态页面兼容 | **首版核心** |
| 阅读个性化 | 译文样式、目标语言、站点规则、快捷键 | 样式隔离、配置优先级 | 首版做基础设置 |
| 主流网站定制 | 针对 Google、Twitter、Reddit 等深度适配 | 站点规则持续维护 | 后续按数据决定 |
| 划词/悬停翻译 | 选区翻译、按住快捷键翻译段落 | 选区定位、上下文提取 | 后续版本 |
| 输入框翻译 | 连按三次空格翻译输入内容 | 富文本编辑器、撤销、误触发 | 后续版本 |
| 多翻译引擎 | 20–30+ 种传统翻译与大模型服务 | 接口差异、限流、质量与成本 | 首版接入一家，保留适配层 |
| AI 术语库 | 自定义术语、领域专家 Prompt | 术语一致性、Prompt 管理 | 后续版本 |
| 视频双语字幕 | 50+ 视频站点已有字幕翻译 | 字幕获取、时间轴、站点维护 | 独立专项 |
| 文档翻译 | PDF、ePub、TXT、字幕文件 | 解析、版面还原、导出 | 独立专项 |
| 图片/漫画翻译 | OCR、翻译、图像回填 | 识别精度、排版、处理成本 | 暂不纳入 |
| 会议/无字幕视频 | 语音识别与实时翻译 | 音频采集、实时性、费用 | 暂不纳入 |
| 移动端 | iOS Safari、Android 浏览器 | 平台差异 | 暂不纳入；安卓上狐猴（Lemur）浏览器已实测可装，见 [14 §1.1](./14-release-process.md) |

## 2. 核心判断

1. 难点不在“调用一次翻译接口”，而在于**持续稳定地识别该翻译的内容，并把译文放在正确位置且不破坏网站**。
2. 翻译已有字幕 ≠ 无字幕视频翻译；提取 PDF 文字 ≠ 保留排版翻译；支持普通文章 ≠ 支持社交网站和在线编辑器。这些必须分开立项。
3. 商业版由平台统一提供翻译，成本与配额控制是与体验同等重要的核心能力。
4. 借鉴功能和交互目标，不复制对方品牌、素材或专有实现。

## 3. 阅渡差异化方向（待验证）

| 方向 | 说明 |
|---|---|
| 专注阅读 | 首版聚焦长文阅读体验，不铺开功能矩阵 |
| 隐私透明 | 清晰说明哪些文本发送到哪里，默认不留存正文 |
| 成本可控 | 按需翻译可视内容，避免长页面一次性消耗额度 |

差异化是否成立，需要在邀请试用阶段以用户反馈验证。

## 4. 版本规划

| 版本 | 范围 |
|---|---|
| 原型（阶段 B） | 本地模拟翻译，验证正文识别、双语渲染、停止与恢复 |
| MVP-A 邀请试用 | 网页双语阅读 + 账号 + 平台翻译后端 + 配额 + 隐私告知 |
| MVP-B 公开商业 | MVP-A + 订阅支付 + 正式上架材料 |
| 后续候选 | 站点自动翻译、划词/悬停、输入框、多引擎、术语库、更多语言 |
| 独立专项 | 视频字幕、文档翻译、图片翻译 |

后续候选进入开发前，需按 [10 风险与决策记录](./10-risks-and-decisions.md) 的变更流程评审。
