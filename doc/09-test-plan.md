# 09 测试与验收计划

> 文档编号：QA-001 ｜ 版本：v0.1 ｜ 状态：待评审

## 1. 测试策略

| 类别 | 重点 | 工具 | 引入阶段 |
|---|---|---|---|
| 单元测试 | 分段、过滤、指纹、过期保护、设置合并 | Vitest + jsdom | B |
| DOM 测试 | 标题、链接、列表、表格、代码块、恢复原文 | Vitest + jsdom | B |
| 动态页面 | 新增节点、SPA 跳转、重复点击、节点复用 | Vitest + 演示页 | B |
| 扩展生命周期 | 弹窗关闭、刷新、Service Worker 终止 | Playwright + 手动 | D |
| 集成测试 | 登录、任务、逐段失败、额度不足、幂等 | 后端测试 + 模拟供应商 | D |
| 故障测试 | 超时、断网、429、5xx、部分结果 | 模拟供应商 | D |
| 安全测试 | 越权、结果注入、凭证泄漏、任意代理、日志 | 手动 + 自动化 | D/E |
| 性能测试 | 首批译文时间、长页面卡顿、内存 | Chrome DevTools | E |
| 翻译质量 | 漏译、术语、数字、否定、上下文一致 | 固定语料人工评审 | B7/E |
| 商业化 | 支付重放、到期、退款、对账 | 支付沙箱 | F |

自动化测试默认使用本地固定页面与模拟服务；真实供应商测试需单独预算授权。

## 2. 固定测试页面集

至少 30 个页面，覆盖：

| 类型 | 数量（建议） |
|---|---|
| 技术文档 | 8 |
| 博客/长文 | 8 |
| 新闻 | 6 |
| 列表与表格密集页面 | 3 |
| 动态加载 / SPA | 3 |
| 边界页面（代码多、短文本多、嵌套深） | 2 |

为保证可重复，页面保存为本地快照用于自动化；在线页面仅用于手动兼容性抽查。

**当前实现：**`tests/fixtures/pages/` 共 30 个页面（文档 8、博客 8、新闻/百科/论坛 6、表格与列表 3、应用与动态 3、边界 2），均为自写内容、模拟真实网站结构，不复制第三方文字。标注规则与历次结果见 `tests/fixtures/README.md`，运行 `npm run eval:extraction` 查看明细。

## 3. 质量基线（技术验证后冻结）

| 类别 | 验收要求 |
|---|---|
| 功能 | 所有 P0 需求通过 |
| 正文识别 | 人工标注集上精确率、召回率目标均 ≥ 95% |
| 排版与交互 | 测试集无阻断阅读、点击或导航的问题 |
| 恢复原文 | 恢复后扩展插入节点与标记数为 0 |
| 生命周期 | 弹窗关闭不影响任务；Worker 重启后状态正确 |
| 费用 | 重试不重复扣额、并发不超扣、异常预留可释放 |
| 安全 | 无高风险越权、凭证泄漏、注入问题 |
| 隐私 | 正文不进入默认日志、错误上报与埋点 |
| 发布 | 商店描述、权限说明、隐私政策与实际行为一致 |

## 5. 发布门槛

1. 所有 P0 功能通过；
2. 无阻断使用的已知缺陷；
3. 无高风险安全问题；
4. 测试页面集达到质量基线；
5. 费用上限、告警与熔断完成故障演练；
6. 商店材料与实际行为一致。
