# 03 产品需求规格说明书（PRD）

> 文档编号：PRD-001 ｜ 版本：v0.1 ｜ 状态：待评审

## 1. 首版用户流程

```text
安装扩展 → 查看隐私说明 → 登录账号 → 打开英文网页 → 点击翻译
→ 阅读原文与译文 → 停止翻译或恢复原文 → 查看剩余额度
```

首次上传文本前必须告知：

> 待翻译文本将通过阅渡平台后端发送给翻译服务供应商处理。

首版不默认开启任何网站的自动翻译。

## 2. 功能需求

### 2.1 P0：邀请试用必须具备

| 编号 | 功能 | 验收标准 |
|---|---|---|
| FR-01 | 页面可用性检查 | 不支持的页面（如 `chrome://`、商店页）给出明确原因，不静默失败 |
| FR-02 | 手动启动翻译 | 仅在用户操作（弹窗按钮、右键菜单、快捷键）后识别并提交内容 |
| FR-03 | 正文识别与分段 | 识别标题、段落、列表、引用；跳过脚本、样式、代码块、输入与可编辑区域 |
| FR-04 | 双语渲染 | 译文显示在对应原文之后，原文链接、按钮保持可用 |
| FR-05 | 恢复原文 | 只移除扩展插入或修改的内容，不覆盖网站自身后续变化 |
| FR-06 | 按需翻译 | 优先处理可视区域及附近内容，不一次提交整篇长页面 |
| FR-07 | 基础动态内容 | 已启动翻译的页面中，新增正文进入翻译队列 |
| FR-08 | 停止与重试 | 停止后不再提交新任务、晚到结果不再插入；失败段落可重试 |
| FR-09 | 基础设置 | 目标语言、界面语言、译文字号、颜色、间距可配置并即时生效 |
| FR-10 | 账号与配额 | 身份与额度由服务端校验和结算 |
| FR-11 | 错误提示 | 区分未登录、额度不足、网络失败、限流、供应商故障 |
| FR-12 | 隐私与禁用控制 | 数据处理告知、本地站点禁用列表、本地缓存清理 |
| FR-13 | 翻译范围 | 弹窗可选“正文”（默认，只翻主内容）或“整页”（另含菜单、标签页、表单标题、按钮、提示条等界面文字）；两种模式都不读取输入框、代码和隐藏内容；切换后自动重新翻译 |
| FR-14 | 目标语言列表 | 提供 44 种目标语言，按地区分组并可搜索（支持界面语言名、语言自称、语言代码）；所选翻译服务不支持的语言在列表中置灰不可选 |
| FR-15 | 划词查词 | 选中网页文字后出现查词按钮，鼠标停在按钮上（或点击）即展示译文，内容逐字出现；选中单个词时另给音标（可朗读）、词性释义和它在该句中的含义；可在设置页关闭 |
| FR-18 | 悬浮按钮 | 触屏设备上页面里出现悬浮按钮：点一下翻译 / 显示原文，展开后有朗读、双语 / 仅译文、本页隐藏；可上下拖动并记住位置；设置页可改为总是显示或不显示 |
| FR-17 | 显示模式 | 弹窗「翻译」按钮左侧的开关在「双语对照」与「仅译文」之间切换，悬停提示当前状态；已翻译页面即时切换，不需重新翻译；仅收起已有译文的段落 |
| FR-16 | 朗读译文 | 翻译后弹窗出现「朗读译文」：只读文章标题与正文（按页面结构识别，排除菜单、侧栏、链接、日期等），按段排队，从屏幕可见段落读起，翻译新内容时自动接着读；页面跟着朗读自动往下滚，读到**这篇文章的末尾**为止（不滚进下一篇）；点「停止朗读」或「显示原文」即停；浏览器有自然语音（Edge）就用它，没有（Chrome）且已登录则用服务器的神经语音，失败自动退回本地语音 |
| FR-19 | 视频字幕翻译 | 翻译页面里视频的字幕：播放器提供字幕轨时整轨一次性译好，播放不等待；播放器自己绘制字幕（YouTube、video.js 等）时按句翻译：YouTube 等站点：读取播放器下载的字幕文件（含自动生成字幕），按字幕自带的时间码整份提前翻译，播到哪句显示哪句，与画面同步；读取不到时退回读屏幕字幕，等它停止变化约 0.3 秒（最长 0.8 秒）后翻译，原文与译文成对出现，等待期间保留上一对不闪烁；缩略图级别（宽度 < 240 px）的播放器不接管。译文叠在画面下方，默认双语（原文在上、译文在下），「仅译文」模式只显示译文；进入全屏跟随显示。翻译失败的那句保留原文，不留空。**原文与译文作为一个整体，可用鼠标拖动到画面任意位置**，位置被记住；译文带底色块，**底色与文字颜色在设置页可改**；播放器自己的字幕会被隐藏，避免原文出现两次。随「翻译此页」开始、「显示原文」停止。**YouTube 播放器控制栏里有阅渡自己的按钮**，一键开关字幕翻译，菜单里可切换双语对照/仅译文、改译文文字色与底色、恢复字幕位置；**其他网站的视频**在有字幕可读时，鼠标移上去会在画面右上角出现阅渡角标，打开同样的菜单 |
| FR-26 | 输入框翻译 | 在输入框里打完字后，连按三个空格或按 Alt+Enter，把输入内容就地换成译文（目标语言在设置里单独选，默认英语）。**默认关闭**，设置里可选「连按三个空格 / Alt+Enter / 两者都开」；替换以浏览器的“输入文字”方式完成，Ctrl+Z 可撤回；有选中文字时 Alt+Enter 只翻选中部分，三个空格翻整个输入框；翻译失败或等待期间文字被改动，则原文不动并提示；只在触发那一刻发送文字，平时输入不读取、不上传；密码框、只读与禁用的框不处理；输入法组字期间不计空格；已关闭的网站不触发。设置页启用后显示一行用法提示 |
| FR-27 | 行内公式保护 | 句子里的公式（MathML、KaTeX、MathJax、LaTeXML）翻译前换成 `[[n]]` 占位符发出，译文回来后在占位符位置放回页面上原来的公式；占位符被引擎吞掉时，公式补在句尾而不是消失；只含公式的段落不翻译。**上标与下标按同样方式处理**（BERT<sub>BASE</sub>、脚注号），保留原样式 |
| FR-28 | 不翻词表 | 特殊符号（[MASK]、[CLS]、[SEP]…）、arXiv 编号、DOI、网址、引用（Peters et al., 2018a）、像标识符的名字（BERT_LARGE、GPT-3、RoBERTa）、Transformer/Adam/Softmax，以及正文里的全大写缩写，以 `[[Tn]]` 发出并在译后还原；整句大写的标题不处理；占位符被吞时该句不带占位符重新翻译；**表格单元格里**所有像名字的词（含 `ESIM+GloVe`、`SST-2`、`QNLI`）整条保护，只剩名字的单元格不发给翻译服务；译文与原文相同时不显示 |
| FR-34 | 生词本 | 划词查词的气泡里有星标，点后把该词（原文、译文、音标、释义、所在句子）和页面地址（去掉查询参数与片段）存进本机存储；同一个词（不分大小写）只存一次；最多 2000 个，满了再收藏会提示不再加入；设置页「生词本」：搜索、逐个删除、清空（要确认）、导出 CSV；CSV 带 BOM，以 = + - @ 开头的单元格前加撇号，防止被表格当公式执行；读存储时一律按不可信数据校验。不上传，隐私政策第 15 条写明。**不含同步** |
| FR-35 | 生词复习与 Anki 导出 | 简化版 SM-2（只分「没记住/记住了」两档，不是完整四档）：新收藏的词立即到期；记住了按 1 天 → 6 天 → 上次间隔×难度系数 递增，没记住退回 1 天并降低难度系数（不低于 1.3）。设置页「生词本」新增复习条：到期数量、「开始复习」按钮，进入逐词卡片（显示原文→点「显示释义」→评「没记住/记住了」→下一词），复习结果写回本机存储；工具栏图标角标显示当天到期数（写入生词本或打开弹窗/设置页时更新，纯被动触发，没有后台定时器，到期数不会单靠时间流逝自动刷新）。另有「导出 Anki」：制表符分隔的 .txt，带 `#separator`/`#html`/`#notetype`/`#columns` 注释行，供 Anki 的文本导入自动识别格式；字段里的制表符与换行被替换，不破坏导入。**不含跨设备同步** |
| FR-33 | 自带密钥（OpenAI 兼容） | 服务引擎新增「自带密钥」：设置页填服务地址（https，或仅限本机的 http，如 Ollama）、模型名、密钥；密钥单独存在本机，不进 Settings；段落直接从浏览器发给该地址，不经阅渡服务器、不计额度；首次需用户点「测试连接」并授权访问该地址（可选主机权限，按需申请）；批量以 JSON 数组请求，格式不对则逐条请求；**不参与自动切换，失败也不会把文字改发给别的服务**；译文缓存键含地址与模型；隐私政策第 14 条写明。已核对可用的写法：OpenAI（`https://api.openai.com/v1`）、Anthropic 的 OpenAI 兼容地址（`https://api.anthropic.com/v1`，官方说明它主要用于试用与对比、不建议长期生产使用）、Ollama（`http://localhost:11434/v1`）；某些模型只接受默认的 temperature（推理类模型、Claude 较新的模型），遇到这种 400 会自动去掉该参数重试并记住；网页、字幕、输入框翻译随所选引擎使用；划词查词的词典条目（音标、释义、上下文）也由自己的服务生成，不需要 VIP；朗读不发给阅渡服务器，改用浏览器自带声音 |
| FR-32 | 译文本地缓存 | 译文以「引擎＋目标语言＋原文」的 SHA-256 为键保存在本机 IndexedDB（只存译文，不存原文），下次遇到相同段落直接取用、不发请求；换引擎或目标语言即不命中；最多约 4000 条、30 天，超出先删最久未用；缓存出错（隐私窗口、磁盘满）时直接跳过；设置页有开关（默认开）和「清除缓存」；隐私政策第 13 条写明 |
| FR-36 | 行内代码/命令保护 | 句子里的 `<code>`/`<kbd>`/`<samp>`/`<var>`/`<tt>`（命令、参数、函数名、环境变量等）翻译前换成 `[[Cn]]` 占位符发出，和公式占位符同一思路，但按文本还原（不是克隆 DOM 节点）；占位符被引擎吞掉时，原样补在句尾；只含行内代码、没有其他文字的段落不翻译（与之前一致，`<pre>` 代码块仍整体不翻，“只翻注释”未做，见 25 §1.1） |
| FR-31 | 引擎自动切换与译文语言校验 | 所选翻译服务出错、被限流，或返回的译文不是目标语言（按文字字符集判断，源文足够长、至少两个词才判断）时，只对失败的段落换下一个免费服务重试，最多再试 2 个；顺序：谷歌免费 → 微软 → 其他免费模型；换用的服务需要登录的，未登录就跳过（未登录时实际只剩谷歌免费可换）；**绝不换到 VIP 或付费服务**；全部失败则保留第一个服务给出的结果或错误。设置里一个开关（默认开），隐私政策第 12 条写明。**译文缓存按实际作答的服务存**，不按用户选的服务存，避免切换后的译文冒充成所选服务的结果（2026-10-29）|
| FR-30 | 术语整页统一 | 页面上重复出现（≥2 次）的、大写开头的多词术语（最多 40 个），翻译前各自单独翻译一次，之后各段落共用这一个译法（以占位符发出、译后填入）；单独翻译失败或译文与原文相同的术语不锁定；参考文献（LaTeXML 结构）：首块作者与年份、编号标签、整行斜体的行（如 arXiv preprint）不处理，标题与刊物行各自翻译，块内缩写一律保护；简体中文下另有一份内置术语表（字符级、自注意力、预训练、微调等十余个） |
| FR-29 | 句内链接与脚注 | 句子中间的链接（论文引用等）算进所在句子，不再单独成条；LaTeXML 脚注内容（`.ltx_note_content`）作为独立于所在段落的一条翻译，正常显示译文，不被吸收进正文重复一遍（2026-10-29 改：此前当成悬浮提示整体不翻，但 ar5iv 实际把脚注排成始终可见的边注，导致脚注一直是英文，见 doc/24 §3）；抽取逐字遍历时跳过被样式表隐藏（`display:none` 等）的子元素，不读、不发、不计数，避免页面上看不到的回链标记（如脚注里的 `.ltx_tag_note`）混进译文；`<math>` 等外来内容不做此项检查，按原样整体复制；判断"整句译文该插在哪"时专门跳过脚注记号，不当成"容器里还套着一段话"处理，避免译文被插到脚注记号前面、把句子从中间断开；菜单里单独的链接仍是独立条目 |

## 3. 业务规则

### 3.1 翻译规则

- BR-01 原文默认保留，译文作为独立节点插入。
- BR-02 页面跳转后，旧任务结果不得插入新页面。
- BR-03 段落文本已变化时，丢弃对应旧文本的译文。
- BR-04 单段失败不影响其他段落的已有结果。
- BR-05 不翻译密码框、输入框和可编辑区域。
- BR-06 译文作为纯文本渲染，不解析为 HTML。

### 3.2 停止与恢复

| 操作 | 行为 |
|---|---|
| 停止翻译 | 停止提交新任务；阻止晚到结果插入；保留已显示译文 |
| 恢复原文 | 执行停止，并清理扩展添加的全部译文与标记 |

已提交给供应商的请求不保证可撤销，计费规则见 [06 接口与数据设计](./06-api-and-data.md)。

### 3.3 配额规则

- BR-10 服务端是额度的唯一可信来源。
- BR-11 同一逻辑请求重试不得重复扣额。
- BR-12 多标签页并发不能绕过额度限制。
- BR-13 失败、部分成功、取消分别按明确规则结算。
- BR-14 用户额度账本与供应商成本账本分离。

## 4. 支持边界

**首版优先支持：**普通 HTML 文章、博客、技术文档；可识别正文的简单动态页面。

**首版不承诺：**

- Chrome 内部页面、Chrome 应用商店页面等受限页面；
- 浏览器内置 PDF 阅读器；
- 图片与 Canvas 中的文字；
- 封闭 Shadow DOM；sandbox 且不含 `allow-same-origin` 的 iframe（不透明源，任何权限都到达不了）；
- 高度虚拟化信息流、复杂在线编辑器。

登录后页面中用户主动翻译的正文可能包含私人信息，需在告知中明确，不宣称“自动保证安全”。

## 5. 非功能需求

| 编号 | 类别 | 要求（候选目标，技术验证后冻结） |
|---|---|---|
| NFR-01 | 正文识别 | 固定测试集上精确率与召回率目标均 ≥ 95% |
| NFR-02 | 首屏速度 | 模拟服务下首批可视译文展示 P95 ≤ 2 秒；真实服务实测后另定 |
| NFR-03 | 页面性能 | 长页面滚动无明显卡顿；任务结束后无持续内存增长 |
| NFR-04 | 稳定性 | Service Worker 终止、弹窗关闭不导致任务状态错乱 |
| NFR-05 | 计费正确性 | 重试不重复扣额、并发不超扣 |
| NFR-06 | 隐私 | 正文不进入默认日志、错误上报与埋点 |
| NFR-07 | 权限 | 只申请当前功能必要权限 |

以上数字为待验证的验收目标，不是已测结果。
