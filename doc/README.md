## 已确认的项目基线

| 项目 | 结论 |
|---|---|
| 产品性质 | 商业产品 |
| 首版场景 | 网页双语阅读 |
| 默认语言方向 | 英语 → 简体中文（待评审确认） |
| 翻译服务 | 免费档：谷歌免费接口（浏览器直连，默认）、微软翻译 F0；付费档：谷歌官方 API、OpenAI（官方 API 均经服务器，密钥只在服务端） |
| 开发期费用 | 每月 $10 以内（服务器强制上限） |
| 推进方式 | 先评审文档，再开发；先邀请试用，再正式收费 |
| 首版排除 | PDF、OCR（视频字幕、输入框翻译、划词查词已先后实现） |
| 当前方向 | 学术论文阅读为首发楔子（2026-10-28，见 [24](./24-academic-direction.md)） |

## 文档维护规则

1. 需求编号（如 `FR-04`）贯穿需求、设计、开发任务和测试用例。
2. 文档中标注“建议”“待定”“待验证”的内容，未经确认不得作为对外承诺。
3. 需求冻结后的变更，按 [风险与决策记录](./10-risks-and-decisions.md) 中的变更流程处理。
4. 实现与文档不一致时，同一次变更中修正文档。
