# 08 开发实施计划

> 文档编号：PLAN-001 ｜ 版本：v0.1 ｜ 状态：待评审

## 1. 实施原则

1. 先验证最难、最影响产品成立的部分；
2. 每个阶段有可检查的交付物与退出条件；
3. 扩展与后端按完整用户流程纵向迭代，不各自开发到最后才集成；
4. 功能、测试、隐私与费用控制同步建设；
5. 以验收门槛推进，不承诺未经验证的日期。

## 3. 依赖关系

```text
范围确认 → 核心技术验证 → 详细设计 → 邀请试用版开发
→ 测试与试用 → 商业化评审 → 正式收费与上架
```

- 供应商选择依赖真实语料评测和预算；
- 定价依赖试用期真实成本；
- 支付选择依赖经营主体和市场地区；
- 自动翻译依赖额外权限与告知设计。

## 5. 本地开发命令（阶段 B 起）

| 命令 | 作用 |
|---|---|
| `npm install` | 安装依赖 |
| `npm run build:ext` | 构建扩展到 `dist/`（谷歌免费翻译，无需服务器；**不含账号功能**） |
| `npm run build:ext:local` | 构建连接本地后端 `http://127.0.0.1:8787` 的扩展 |
| `npm run server` | 启动后端（读取 `server/.env`，见 11 文档） |
| `npm run dev` | 监听构建 |
| `npm run typecheck` | 类型检查 |
| `npm test` | 单元测试 |
| `npm run check` | 类型检查 + 测试 + 构建（扩展与官网） |
| `npm run eval:extraction` | 正文识别评测：输出各页面精确率/召回率与误识别、漏识别明细 |
| `npm run preview` | 启动本地演示页 `http://127.0.0.1:4173` |
| `npm run site` | 构建官网到 `website/dist/` 并预览 `http://127.0.0.1:4174`（`npm run site:build` 只构建） |
| `npm run release` | 构建公开版并打包 zip 到 `release/build/`（见 14 文档） |
| `npm run store-assets` | 用本机 Chrome 生成七种语言的商店截图与宣传图到 `release/assets/` |

在 Chrome 打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”并指向 `dist/`。

### 5.1 原型手动验收清单

1. 打开演示页，点击扩展图标，确认隐私说明后点击“翻译此页”（默认为谷歌免费翻译，需能访问 Google；否则连接服务器后切换为微软翻译）；
2. 标题、段落、列表（含嵌套）、表格出现中文译文；代码块、中文段落、`translate="no"` 段落、输入框、导航与页脚不翻译；
3. “错误处理”段落首次显示失败与“重试”按钮，点击后成功；
4. 向下滚动，远处段落在接近时才翻译；
5. 点击“Load more”，新段落自动翻译；
6. “停止”后已显示译文保留；“显示原文”后译文全部移除；
7. 在设置页修改字号、颜色、间距、标识线，页面即时生效；
8. 将 `127.0.0.1` 加入禁用网站，确认无法启动翻译；
9. 右键菜单与 `Alt+Y` 可切换翻译 / 原文；
10. 在 `chrome://extensions` 页面打开弹窗，提示受限页面。
