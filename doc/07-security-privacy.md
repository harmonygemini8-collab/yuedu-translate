# 07 安全与隐私设计

> 文档编号：SEC-001 ｜ 版本：v0.1 ｜ 状态：待评审

## 1. 数据流与告知

| 数据 | 是否离开浏览器 | 去向 |
|---|---|---|
| 待翻译段落文本 | 是（选择谷歌免费） | 浏览器直接 → Google（translate.googleapis.com），不带 Cookie |
| 待翻译段落文本 | 是（选择微软、硅基流动的免费模型、谷歌官方 API 或 OpenAI） | 阅渡服务器 → Microsoft Translator / SiliconFlow（Qwen3-8B、GLM-4-9B、混元 MT-7B）/ Google Cloud Translation / OpenAI |
| 划词选中的文字及其所在句子 | 是（用户点击查词按钮后） | 单词且为 VIP：阅渡服务器 → OpenAI；其余情况与段落文本同路（谷歌免费直连，或经阅渡服务器转发给所选服务） |
| 朗读的译文片段（单次最多 500 字符） | 默认否；仅当浏览器没有自然语音且用户已登录时是 | 阅渡服务器 → 微软 Azure AI Speech 合成语音；服务器不保存文字和音频，只记字符数。Edge 等自带自然语音的浏览器不发送 |
| 网页 URL、DOM、Cookie、表单 | 否 | — |
| 设置、站点禁用列表 | 否（存于 `chrome.storage.local`） | — |
| 开发访问令牌 | 与平台通信 | 阅渡服务器（存于 `chrome.storage.local` 的独立键，不进入 Settings 对象） |

划词查词只在用户点击气泡上的按钮后发生，选中即不发送；所在句子取自选区所在的块级元素，上限 600 字符，用于让模型解释该词在此句中的含义。划词查词里的单词朗读由浏览器本地语音合成完成，不产生网络请求。「朗读译文」默认也用本地语音；只有浏览器没有自然语音（如 Chrome）且用户已登录时，才把正在读的那一小段译文发到阅渡服务器合成语音，失败或额度用完则自动退回本地语音。

未注入后端地址的构建只会请求谷歌免费接口，不访问阅渡服务器。OpenAI 请求设置 `store: false`；阅渡服务器日志不含正文与译文。

不得宣传“数据不离开本机”。供应商对数据的保存与训练政策需如实披露，不代替供应商做未经验证的承诺。

## 2. 扩展安全基线

1. **最小权限：**仅 `activeTab`、`scripting`、`storage`、`contextMenus`，**不声明任何 `host_permissions`**。两个翻译接口都允许跨域请求：谷歌免费接口返回 `Access-Control-Allow-Origin: *`，阅渡服务器只对 `chrome-extension://` 来源回送放行头（普通网页拿不到，因而读不到任何响应）。这样扩展详情页不会列出它可能访问的网址，安装时也不产生主机权限警告。代价是免费谷歌档依赖该非官方接口继续返回 CORS 头，若其取消则需改回声明 `host_permissions` 并重新过审（见 [10 ADR-25](./10-risks-and-decisions.md)）。站点权限放在 `optional_host_permissions`，安装时不申请，未授权的网站不会注册内容脚本。授权有两条路径，都在选项页、都由用户主动发起：添加自动翻译网站时逐站申请，或打开「允许在所有网站上运行」一次性申请 `*://*/*`；两者均可随时调用 `permissions.remove` 收回。全站开关为 0.3.2 新增：嵌入式在线文档的正文常在另一个跨域 iframe 里，那个域名用户无法预先知晓，逐站授权天然覆盖不到。**关键是安装时的权限提示未变** —— 广泛权限提示只在用户主动打开开关时出现。
2. **无远程代码：**所有逻辑随安装包发布，不加载 CDN 脚本、不使用 `eval`/`new Function`。
3. **内容安全策略：**扩展页面使用 Manifest V3 默认 CSP，不放宽。官网 nginx 的 CSP 为 `default-src 'self'`，额外开放 `connect-src 'self' https://api.warptech.cc`（登录页调用 API 必须）和 `font-src 'self' data:`（系统字体内嵌格式）；其余全部禁止，包括 `form-action 'none'`、`frame-ancestors 'none'`。**注意：** 官网页面不能使用 `<style>` 内联块，必须用外部 CSS 文件（`style-src 'self'` 不含 `'unsafe-inline'`）。
4. **不可信输入：**网页 DOM 与翻译结果都视为不可信；译文只用 `textContent` 写入。
5. **消息校验：**校验 `sender.id` 与消息结构，不对网页 `postMessage` 开放接口。
6. **隔离：**Content Script 运行于隔离环境，不向页面暴露扩展对象与凭证。
7. **跳过敏感区域：**不读取密码框、输入框和可编辑区域内容。

## 3. 后端安全基线（MVP-A）

1. 供应商密钥保存在服务端密钥管理服务中，不进入扩展、日志或前端配置。
2. 每个任务的创建、查询、取消都校验用户归属，防止越权。
3. CORS 和扩展 ID 不能作为身份认证手段。
4. 限制文本长度、批量、并发与可用模型，防止成为任意请求代理。
5. 正文不写入应用日志、链路追踪与错误上报。
6. 全链路 HTTPS；凭证有过期与吊销机制。

## 4. Chrome 应用商店合规要点

| 要求 | 落实方式 |
|---|---|
| Manifest V3 无远程托管代码 | 构建产物自包含，审查依赖是否动态拉取脚本 |
| 单一用途 | 商店描述聚焦“网页双语阅读翻译” |
| 最小权限 | 每项权限在商店后台给出用途说明 |
| 用户数据政策 / Limited Use | 网页内容仅用于用户触发的翻译功能，不出售、不用于广告 |
| 隐私政策 | 发布前提供可访问链接，覆盖收集内容、用途、共享方、保留与删除 |
| 显著告知 | 首次上传文本前在扩展 UI 中告知并取得确认 |

## 5. 安全测试清单

- 任务 ID 枚举与越权访问；
- 恶意译文（含 HTML/脚本）注入页面；
- 凭证在扩展存储、页面环境、日志中的暴露；
- 后端被用作任意文本或模型代理；
- 日志、错误上报中出现正文；
- 依赖中是否存在远程代码加载。
