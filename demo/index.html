Reading the Web in Two Languages

A sample article for testing bilingual translation.

Bilingual reading keeps the original text on the page and places the translation right next to it, so you can always check what the author actually wrote.

This page is a local test fixture for Yuedu Translate. It contains headings, links, lists, tables, code blocks and dynamic content.

Why keep the original text?

Machine translation is fast, but it can miss nuance, numbers and negation. Seeing both versions together makes these mistakes easy to spot.

The best translation tool is the one that lets you stop needing it.

What gets translated

  • Headings and paragraphs in the main content area
  • List items, including nested lists
    • Each nested item is translated on its own
  • Table cells and figure captions

What is skipped

Code is never translated. Run npm run build and the command stays exactly as written.

const greeting = "Hello, world";
console.log(greeting);

Text that is already in Chinese is skipped too:

这一段已经是中文，所以不会再被翻译。

Brand names marked as translate="no" stay untouched.

Handling errors

If a paragraph cannot be translated, a retry button appears below it without affecting the rest of the page.

Long pages

Only paragraphs near the visible area are translated first. Scroll down to see the rest of the page being translated on demand.

This paragraph sits far below the first screen and is translated only when you scroll close to it.

Dynamic content

New content that appears after translation starts is detected automatically.
